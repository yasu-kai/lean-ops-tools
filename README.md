# Lean Ops Tools

Independent B2B software discovery and review site for small service businesses.

This repository contains the static launch site used for partner-network onboarding and the first stage of the Lean Ops Tools content platform.

## Pages
- Home
- About
- Editorial Policy
- Affiliate Disclosure
- Privacy

## Deployment
Designed as a zero-build static site and suitable for Vercel deployment directly from GitHub.
